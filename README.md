🎤 Voice Emotion Detection

A Machine Learning project that detects human emotions from voice using audio features. This system is trained on the RAVDESS dataset and can identify emotions like happy, sad, fearful, surprised, angry, disgust, and neutral from speech in real-time.

🌟 About the Project

Voice Emotion Detection is a technology that analyzes vocal features such as pitch, tone, intensity, and speech patterns to determine the emotional state of a speaker. By leveraging machine learning algorithms, this system can recognize emotions like:

😄 Happy

😢 Sad

😱 Fearful

😲 Surprised

😡 Angry

🤢 Disgust

😐 Neutral

Applications include:

- Customer Service – Respond empathetically to users’ emotions.

- Healthcare – Assist in mental health monitoring and stress detection.

- Human-Computer Interaction – Create natural interactions between humans and AI.

- Entertainment & Gaming – Adapt content dynamically based on emotions.

This technology enables smarter, more responsive AI systems that understand human emotions in real-time.

🛠 Features

- Detects multiple emotions from voice recordings.

- Trained on the RAVDESS dataset for reliable performance.

- Supports real-time emotion recognition from live audio.

Built using Python and popular ML libraries for audio processing.

📂 Dataset

RAVDESS (Ryerson Audio-Visual Database of Emotional Speech and Song):

- 24 professional actors (12 male, 12 female)

- 7 emotions: happy, sad, fearful, surprised, angry, disgust, neutral

- Speech recordings used for model training

⚡ Tech Stack

- Python – Core programming language

- Librosa – Audio feature extraction

- Scikit-learn – Machine Learning modeling

- NumPy & Pandas – Data handling and preprocessing

- Matplotlib & Seaborn – Data visualization

🚀 How It Works

- Preprocessing – Load audio files and extract features like MFCC, chroma, and mel spectrogram.

- Model Training – Train ML models to classify emotions based on audio features.

- Prediction – Input a voice sample to predict the emotion in real-time.

🎯 Applications

- Emotion-aware virtual assistants

The trained model achieves high accuracy in recognizing emotions from voice, enabling AI systems to respond empathetically and improve user experience.
